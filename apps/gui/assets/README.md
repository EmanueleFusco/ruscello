# Bundled fonts

- Inter 4.1 from the [Inter project](https://github.com/rsms/inter/tree/v4.1), instantiated at weight 400 and optical size 14, then subset to Latin characters and UI symbols. See [Inter-OFL.txt](Inter-OFL.txt).
- Lucide 0.562.0 from the [lucide-static distribution](https://www.npmjs.com/package/lucide-static/v/0.562.0), subset to the glyphs used by the application. See [Lucide-LICENSE.txt](Lucide-LICENSE.txt).
